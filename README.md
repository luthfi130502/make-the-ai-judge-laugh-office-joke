## What it does

`main.py` writes one original office joke — a single line of UTF-8 text,
1–200 characters — to `/output/entry.txt`:

> To keep the daily standup under fifteen minutes, we removed all the chairs. That was 2019. The meeting never ended, and the chairs now hold their own standup without us.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

No dependencies beyond Python 3.
